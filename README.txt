BUSHRA'S CLICK-THROUGH BIRTHDAY WEBSITE
========================================

Open index.html and press "Start the surprise".

Use the bottom arrows, page dots, keyboard arrow keys, or mobile swipes to move
through the six full-screen chapters. The site includes Bushra's photos, a
separate apology note, a separate blessing, chocolates, wishes, music,
confetti, fireworks, and an interactive birthday candle.

Keep index.html, styles.css, script.js, and the assets folder together.
The active music file is assets/bushra-birthday-song.mp3.
